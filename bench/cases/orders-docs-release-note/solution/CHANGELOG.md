# 변경 기록

## [1.2.0] - 2026-11-20

### 추가
- 주문의 일부 라인만 환불하는 `refundLines`를 추가했습니다. 환불액은 할인을 비례 배분해 계산합니다.
- `placeOrder`에 멱등 키 옵션을 추가했습니다. 같은 키로 다시 요청하면 기존 주문을 돌려줍니다.

### 변경
- 라인당 최대 주문 수량을 99개에서 50개로 줄였습니다.

### 수정
- GOLD 등급 할인액을 반올림하던 문제를 정책대로 원 단위 내림으로 고쳤습니다.
- 재고 부족으로 주문이 실패할 때 예약하지 않은 상품의 재고까지 늘어나던 문제를 고쳤습니다.
